# 0002. Matek H743-SLIM V3 flight controller

Date: 2026-09
Status: Accepted

## Context
ArduPilot's ROS 2 (DDS) support should be used on H7-based boards; F4 and F7 boards don't have the processing headroom. I also need several spare serial ports (receiver, GPS, companion computer) and an SD card for logs.

## Options
- **Pixhawk 2.4.8 clones:** cheap and common, but F4-based (too slow for DDS) and clone quality varies.
- **Holybro / CubePilot H7 boards:** excellent, but several times the price.
- **Matek H743-SLIM V3:** H7, 7 UARTs, 13 outputs, SD slot, well supported by ArduPilot (the MatekH743 target), about ₪215.

## Decision
Matek H743-SLIM V3.

## Consequences
- No built-in current sensor, so an external power module measures current.
- Its 5 V BEC is 2 A, not enough for a Pi, so the Pi gets its own UBEC.
- Fakes exist on AliExpress: check the board against Matek's photos.
