# ArduPilot parameters

Save the full parameter list at every milestone: Mission Planner → Config → Full Parameter List → Save. Name the files by date and stage:

```
2026-11-05-bench-setup.param
2026-11-20-before-first-flight.param
2026-11-28-after-autotune.param
```

To see what changed between two files: Mission Planner's Compare Params button, or `diff`.
